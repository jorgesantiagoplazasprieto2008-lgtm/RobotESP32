# RobotESP32
Aplicación Web para el control y uso del dispositivo electronico RobotESP32

# Pasos previos a su uso
- Encender el Robot previamente cargado con la energia suficiente para poder controlarlo.
- Conectarse a la red wifi que emite el RobotESP32 denominada "KUONGSHUN-AD175" con la contraseña "12345678".
